## 2. Хронология: где именно начался «слив»

Дневная динамика (Reports API, только Поиск):

| Период | Клики | Расход | Конв. | **CPC** | **CPL** | CR |

**Ключевой факт: конверсионность трафика НЕ упала (8,2% → 8,0%). Запросы остались теми же. Подорожал сам клик — почти вдвое.** Это не «пошёл мусорный трафик» — это инфляция аукциона, которую стратегия послушно оплачивала.

Почему так произошло — три причины, по убыванию вклада:

1. **Стратегия «Средняя цена клика 120₽» разрешала платить дорого.** В апреле кампания была новой, аукцион выкупался по факту за ~64₽ — вдвое ниже потолка. В мае конкуренция выросла (май — пик сезона тонировки и плёнки в Казани: до +100% к ставкам), и стратегия стала честно догонять среднюю до заданных 120₽: майский фактический CPC — 123₽. Формально стратегия работала «как настроено». Отдельные клики уходили по 300–460₽: «химчистка авто казань» — 465₽ за клик, «оклейка авто плёнкой казань» — 409₽.
2. **Майские праздники (1–10 мая):** спрос упал (показы просели вдвое), а CPC вырос — 3 мая 5 кликов стоили 974₽ (195₽/клик). Две недели кампания жгла деньги в полупустом аукционе.
3. **Автотаргетинг: 6 140 показов, 65 кликов, 1 752₽ — 0 конверсий за всю историю.** Плюс разовый всплеск РСЯ 22 мая: 68 кликов с игровых площадок (маджонги, DSP-биржи) за 596₽, 0 конверсий — в тот же день РСЯ правильно выключили через SERVING_OFF.

## 4. Решения

### Немедленно (до перезапуска)

1. **Восстановить кампанию из архива** — сейчас канал просто мёртв, а апрель доказал: юнит-экономика сходится (CPL 778₽ при цели 1 500₽).
2. **Сменить стратегию.** «Средняя цена клика 120₽» — виновник мая. Конверсий 6–7/нед → жёсткий CPA ставить рано. Поставить **«Максимум кликов» с недельным бюджетом 7 500₽ и ограничением максимальной ставки 90₽** — это отрежет клики по 300–460₽, из-за которых CPL удвоился. Через 3–4 недели, при 10+ конв./нед — перейти на «Оптимизацию конверсий» с CPA 1 200–1 500₽.
3. **Автотаргетинг — только категория «целевые запросы»** (в ЕПК на Поиске полностью выключить нельзя). 1 752₽ → 0 конверсий: остальные категории (широкие, альтернативные, сопутствующие) снять.
4. **Долить минус-слова** (товарка всё ещё проскакивает): `купить, !пленка для, рулонная, фотохромная, tenet, тон эксперт, оптовая, самоклеющаяся, лучше чем, или пленка, чем отличается, ларгус, перетяжка`. В кампании уже ~140 минусов — список обновляется через API только целиком (get → merge → update).

### Структура (при перезапуске)

Разделить на **2 ЕПК** с независимыми бюджетами:

1. **«Детейлинг + уход»** (детейлинг, полировка, керамика, химчистка, антихром) — 7 500₽/нед. Посадочные: `/`, `/polirovka`, `/himchistka`, `/antihrom`, `/detayling-kuzova`.
2. **«Плёнки + тонировка»** (PPF, бронеплёнка, оклейка, тонировка) — 5 000₽/нед. Посадочные: `/ppf`, `/broneplenka`, `/oklejka-avto`, `/tonirovka`. В объявлениях: «работа под ключ, не продаём материал» — режет товарный трафик до клика.

Генерик-ключи плёнки без «казань» **оставить** (гео-таргетинг и так Казань; в апреле они дали самые дешёвые конверсии), но следить за товаркой через минусы.

### Корректировки

- Desktop: **−30%** (данные выше).
- Гео: Казань + 20 км, без расширений.
- РСЯ: держать выключенным. Вернуться только ретаргетингом при ≥300–500 визитов/нед.

### Сезонная защита (чтобы май не повторился)

- Раз в неделю смотреть фактический CPC в отчёте: **рост >30% за неделю = сигнал резать max-ставку**, а не «подождать».
- На праздничные недели (майские, НГ) — снижать недельный бюджет вдвое или ставить паузу: спрос падает, аукцион дорожает.
- Недельный ритуал (30 мин): отчёт «Поисковые запросы» → минусы; контроль CPL по двум кампаниям раздельно.
