## 9. Возможности для вау-эффекта в рамках бюджетов

Бюджеты держим по `03-template-service.md` §6. Медиана LCP mobile на production (3 прогона, §4.3) ниже порога 2,5 с на всех шаблонах; разница до порога: главная 1895 мс (−605 мс), `/ustanovka-signalizacii` 2226 мс (−274 мс), `/blog` 2190 мс (−310 мс). Худший из трёх прогонов у сигнализаций 2235 мс, у `/blog` 2313 мс — тоже ниже порога, но разница меньше 0,3 с, и любой тяжёлый эффект в первом экране может её съесть. Поэтому вау-эффект добавляем точечно и принимаем по замеру на production:
- **Анатомия → расчёт.** Зона → услуга → «от N ₽» → квиз с предзаполнением. Блок уже есть, нужна связка с ценой.
- **Микроны ЛКП** (`/polirovka`). Починить CTA (F2) и повторить приём для PPF и керамики — CSS + лёгкий JS.
- **Сезон сигнализаций.** `SeasonBar` с честным «до морозов N дней» и кейсом прогрева на `avtozapusk`, без видео.
- **Hero-видео** — только desktop. На мобильном — постер в правильном разрешении (F15) и `font-display: optional` — профилактика сдвига от шрифта (F3, P3: медианой не подтверждён).
- На сигнализациях и в блоге сначала увеличить запас по LCP (F4), и только потом добавлять эффекты.
