Основа: токены + ДС §4.8 + инвентаризация §1.3. Meta 1:1.

## /portfolio (список)

1. Header. 2. Хедер страницы: breadcrumbs → H1 1:1 → фильтры категорий (текущие, pill-чипы; активный — accent-subtle + border accent; фильтрация клиентская, URL ?filter= сохранить как сейчас).
3. Сетка кейсов: 12 карточек (акцентные Rolls/Lambo — span 2). Карточка CaseCard: фото 4:3 → scrim → марка font-display + теги услуг. Данные 1:1.
4. CTA-блок «Хотите так же?» → один квиз (generic-конфиг) — вместо двух текущих форм.
5. Footer + sticky CTA.

**Кейсы-дубли:** в `next.config` добавить 301: polirovka-work-1→porsche-cayenne-polish, work-2→mercedes-gla-polish, work-3→bmw-420d-detailing, work-4→mercedes-gla-polish, work-5→porsche-cayenne-polish, work-6→bmw-420d-detailing. В сетке — 12 именованных.

## /portfolio/[slug] (кейс)

Два режима по данным:
- **Разворот** (4–6 флагманов, контент придёт в `content/cases/` этапом 4): хедер-фото 21:9 + scrim + марка H1 + теги + факты (срок/пакет/год) → блоки «Задача» (текст 4 кол + фото 8 кол) → «Процесс» (фото-ряд 2–3, reveal stagger) → «Результат» (before/after или глянец-кадр) → prev/next карточки → квиз.
- **Галерея** (остальные): текущая структура — H1 + теги → сетка фото (4+) в лайтбоксе (простой: `<dialog>` + стрелки) → prev/next → квиз.
Параллакс фото разворота: translateY ≤ 6%, desktop only, IO+rAF.

«Оплатим такси от 15 000 ₽» — спокойной строкой в CTA-блоке, без плашки.

SEO: meta кейсов 1:1 (шаблонная генерация сохраняется), альты фото = марка + услуга. DoD: фильтры работают без перезагрузки, 301 отвечают, лайтбокс с клавиатурой, разворот собирается из markdown-файла кейса без правок кода.
