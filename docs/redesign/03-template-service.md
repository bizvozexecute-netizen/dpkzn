# 03 — Шаблон УСЛУГА (эталон: /ppf) · ТЗ для Claude Code

Основа: дизайн-токены `02-design-tokens.json` (импорт в tailwind.config), компоненты `02-design-system.md` (§4), визуальный эталон — канвас «Dark Studio — dpkzn.ru», артборд «Услуга PPF · Desktop». Контент — 1:1 из текущего сайта (инвентаризация `01-inventory.md`); ниже указано, откуда берётся каждый блок. Шаблон один для всех 19 услуг, вариации — флагами в данных страницы.

## 0. Данные страницы (контракт)

Каждая услуга описывается объектом (источник — существующие данные сайта, миграция 1:1):

```ts
type ServicePage = {
  slug: string;                    // URL не меняется
  meta: { title: string; description: string };  // строго 1:1, правок НЕТ (решения 01.09.2026: «стёкл» уже исправлено в seed; на polirovka-far верна цена 2 500 ₽ — правится ПРАЙС, не meta)
  h1: string;
  heroMedia: { videoLoop?: string; poster: string };  // лупы: /video/hero/*, карта — docs/redesign/content/hero-loops.md; нет лупа → фото hero из public/images/hero/{slug}.webp
  usp: string[];                   // 3 коротких факта под H1 (из текущего hero/SEO-текста)
  pricing: PricingModel;           // см. §3 — три модели из инвентаризации
  beforeAfter?: { before: string; after: string };   // есть у: ppf, polirovka, himchistka, tonirovka, antihrom, antidozhd, polirovka-stekol, polirovka-far, zashchitnye-pokrytiya, ustanovka-linz
  steps: { title: string; text: string }[];          // «Как мы работаем», 3–5, тексты 1:1
  quiz: QuizConfig;                // §5
  faq: { q: string; a: string }[]; // 1:1, 5–11 вопросов
  seoText: string;                 // HTML 1:1
  related: { slug: string }[];     // перелинковка 1:1
  crossSell?: { slug: string; text: string };        // бывший скидочный баннер, БЕЗ процентов
};
```

## 1. Секции сверху вниз (desktop 1440; мобайл — по канвасу «Mobile 390» и правилам ДС)

### 1.1 Header + мегаменю
Компонент ДС §4.6 as is. Все 19 услуг в мегаменю по группам инвентаризации. Активный пункт — accent. Sticky-поведение: прозрачный поверх hero → blur-подложка после 40px; скрытие при скролле вниз >400px.

### 1.2 Hero (высота 620px desktop / 520 mobile)
- Фон: `heroMedia.videoLoop` (autoplay muted loop playsinline, poster; prefers-reduced-motion → только poster) или фото. Поверх — `hero-scrim` из токенов.
- Контент снизу: breadcrumbs (Главная / Услуги / {название}; schema BreadcrumbList) → H1 (`h1` fluid, font-display) → строка USP (3 пункта с янтарными точками-маркерами) → CTA-ряд: primary «Расчёт по фото за 15 минут» (скролл к квизу §5) + secondary «Смотреть работы» (якорь на §1.4 или /portfolio).
- LCP = poster/фото: `next/image` priority, видео догружается после onload.

### 1.3 Прайс
Компонент ДС §4.4, данные — §3. Заголовок секции H2 (существующая формулировка страницы, 1:1). Отступ секции `section` (120px).
Порядок: карточки пакетов → (если классы) матрица классов → (если есть) поэлементный прайс со сворачиванием после 8 позиций.
Кнопка «В расчёт» на пакете: prefill квиза (`quiz.preset = packageId`) + плавный скролл к квизу. Строка-дисклеймер «Точная цена — после осмотра или по фото».

### 1.4 Before/After (флаг `beforeAfter`)
Компонент ДС §4.5. Изображения из `public/images/{slug}-before|after.webp` (уже в репо). Одна пара на страницу. Появление в вьюпорте — автоподсказка ручки (однократно).

### 1.5 Этапы «Как мы работаем»
Компонент «таймлайн» ДС §4.8-стиль: сетка N колонок (N=длине `steps`, 3–5), номер `01` accent + линия + заголовок + текст. Тексты 1:1. Mobile: вертикальный список.

### 1.6 Квиз — ЕДИНСТВЕННАЯ форма страницы
Компонент ДС §4.3, конфиг §5. Один инстанс в DOM. Никаких дублей ниже.

### 1.7 FAQ
Аккордеон ДС-стиля (первый пункт раскрыт), H2 «Частые вопросы». Вопросы/ответы 1:1. Разметка FAQPage JSON-LD — заготовки придут в этапе 4 (`content/schema/`). Аккордеон — `<details>`/`<summary>` (SEO-текст в DOM всегда).

### 1.8 Отзывы
Компонент ДС §4.11: лента 6 отзывов (общие для всех страниц, источник — текущий блок), агрегат «5.0 · Яндекс.Карты», ссылка на org 49387442667.

### 1.9 SEO-текст
`prose`-блок (типографика ДС: h2/h3 font-display, body 17/1.6, ссылки underline hover-accent). HTML 1:1, без сокращений. Ширина `prose` 720px.

### 1.10 Рекомендуемые услуги
3–4 ServiceCard (ДС §4.2) по `related` 1:1. Заголовок «Смотрите также» (или текущий 1:1).

### 1.11 Кросс-селл (флаг `crossSell`)
Спокойная широкая карточка: фото услуги + «С этой услугой заказывают: {услуга}» + secondary-кнопка. БЕЗ скидок и процентов. Тексты — из этапа 4.

### 1.12 Footer
ДС §4.7. **Юрреквизиты не публикуем** (решение владельца 01.09.2026) — блока реквизитов в футере нет, плейсхолдер не оставлять. Нижняя строка футера: только «Политика конфиденциальности».

### Sticky CTA (глобальный, поверх)
ДС §4.10: появление после 1.5 вьюпорта, скролл к квизу, WhatsApp/Telegram (+Max в раскрытии). Скрывается на шаге контакта квиза и за 100px до футера.

## 2. Что УДАЛЕНО против текущих страниц (не переносить)
Виджет «Загрузка студии 80% / 2 слота»; «Перезвоним за 28 сек»; «В работе: 4 авто»; второй калькулятор; дубль прайс-таблицы в DOM (одна responsive-таблица); скидочные баннеры (−10/−15%); селектор класса в hero.

## 3. Модели прайса (данные из 01-inventory §3.1, переносятся 1:1)

- `matrix`: пакеты × классы 1–5 (ppf, polirovka, himchistka, tonirovka). Шапка колонок: «Класс N» + примеры моделей (единая система классов — как на himchistka: 1 Rio/Solaris · 2 Camry/X3 · 3 Cayenne/X5 · 4 S-класс/Panamera · 5 Rolls-Royce/Bentley, «по осмотру»). Mobile: сегмент-контрол класса → список пакетов.
- `packages`: 3 тарифа «от X ₽» (broneplenka, oklejka-avto, detayling-kuzova, antikor, ustanovka-signalizacii, zashchitnye-pokrytiya, regulirovka-far, vyezdnoj-detayling). Бейдж «Выбирают чаще» вместо «ХИТ».
- `single`: одна позиция от X ₽ (остальные 6). Рендер: крупная цена + список «что входит».
- `perElement`: опциональный доп-блок для matrix/packages.

## 4. Особые страницы (флаги)
- /ppf — эталон; hero-луп #3 (PPF peel); квиз шаг 2 = зоны оклейки; в шаге зон — кнопка «Показать на машине» → открывает оверлей с 3D-анатомией (ассеты public/anatomy/, синк выбора зон, см. 03-feature-anatomy-3d.md §5–6).
- /polirovka — интерактив микрон ЛКП сохраняется (перенос как есть); луп #1.
- /tonirovka — сравнение % затемнения сохраняется; луп #6.
- /ustanovka-linz, /polirovka-far — луп #7; /zashchitnye-pokrytiya — луп #2; /himchistka, /vyezdnoj-detayling — луп #5; /broneplenka, /oklejka-avto — луп #4; /detayling-kuzova — луп #1.
- Без лупа (antikor, PDR, регулировка, стёкла, антидождь, антихром, сигнализация) — статичное hero-фото из public/images/hero/.

## 5. Квиз (единый компонент, конфиг на услугу)
Шаги: 1) класс авто (1–5 с примерами) → 2) объём работ (опции из прайса страницы; для matrix — пакеты, для packages — тарифы, для single — пропуск шага) → 3) срок («На этой неделе / В этом месяце / Пока считаю») → 4) контакт: телефон (маска +7, валидация 10 цифр) + выбор канала: WhatsApp / Telegram / Max / Звонок.
Отправка: POST в существующий эндпоинт лидов сайта (найти в репо, сохранить интеграцию 1:1; если её нет — API-роут + текущий канал уведомлений студии). В payload: slug, класс, объём, срок, канал, телефон, page URL. Успех — состояние в контейнере (ДС §4.3), без редиректа.
Аналитика: события quiz_step_{n}, quiz_submit в существующий счётчик (Метрика — id взять из текущего кода).

## 6. SEO-инварианты (жёстко)
URL, title, description (без единой правки — allowlist диффа пуст), H1, тексты услуг, FAQ, SEO-текст, перелинковка — 1:1. Один H1. Секции — H2. Canonical как сейчас. Существующие JSON-LD не удалять до замены заготовками этапа 4. `next/image` для всех фото, размеры заданы. JS страницы ≤ 15 КБ gzip сверх пола фреймворка (пол измеряется статической страницей той же сборки — на текущем стеке ~180 КБ; прежние 150 КБ были ниже пола и недостижимы). 3D-анатомия — только на /ppf и лениво.

Lighthouse-гейт (формулировка от 01.09.2026, вместо абсолютного «perf ≥ 90»):
абсолютный балл на локальной машине шумит на ±20 пунктов и ничего не доказывает.
Гейт — **сравнительный прогон**: Lighthouse mobile по текущему боевому
dpkzn.ru/{slug} и по новой странице, подряд, на одной машине, медиана 5 прогонов
каждая; новая обязана быть не ниже старой. Компонентные пороги, которые держим
абсолютно: TBT ≤ 300 мс, CLS ≤ 0.05, LCP в реальном браузере ≤ 2.5 с, SEO 100.
В отчёты идут только медианы, одиночные прогоны — нет.

## 7. Definition of Done шаблона
Страница /ppf собрана на новом шаблоне и проходит: пиксельная сверка с артбордом канваса (допуск — типографика/отступы из токенов), все данные совпадают с текущим /ppf (прайс, FAQ, тексты — diff по текстовому содержимому пустой), мобайл 390px без горизонтального скролла, квиз отправляет лид, sticky CTA один, удалённые виджеты отсутствуют, Lighthouse mobile ≥ 90 perf / 100 SEO.
