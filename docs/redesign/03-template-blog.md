# 03 — Шаблоны БЛОГ: список (/blog), статья (/blog/[slug]), ABOUT и CONTACTS · ТЗ

## /blog (список)
1. Header → breadcrumbs → H1 «Блог» + саб 1:1 → фильтры категорий (9 текущих, как в портфолио).
2. Featured: первая (свежая) статья — горизонтальная карточка (фото 60%).
3. Сетка 3 колонки ArticleCard (ДС §4.12): обложка 16:9 → категория overline accent → заголовок (кламп 2) → дата + время чтения (рассчитывается из объёма текста). Все 25 статей, пагинации нет (как сейчас).
4. Footer + sticky CTA. Никаких форм в списке.

## /blog/[slug] (статья)
1. Хедер статьи: breadcrumbs → категория overline → H1 1:1 → дата + время чтения → обложка 16:9.
2. **Оглавление** (новое): для статей с ≥4 H2 — сворачиваемый блок «Содержание» из H2 (якоря генерируются). Desktop ≥1280: sticky-колонка слева от prose.
3. Тело: prose 720px, HTML 1:1 (заголовки font-display, ссылки underline).
4. **CTA-компакт** (вместо текущей формы): карточка «{Услуга по категории статьи}» — фото + название + «от N ₽» + primary «Расчёт по фото» → ссылка на страницу услуги (маппинг категория→услуга: Защита кузова→/ppf, Полировка→/polirovka, Тюнинг оптики→/ustanovka-linz, Тонировка→/tonirovka, Уход за салоном→/himchistka, Шумоизоляция→/shumoizolyaciya, Детейлинг→/detayling-kuzova, Оклейка и плёнки→/oklejka-avto, Стайлинг→/antihrom).
5. **«Читайте также»** (новое): 3 ArticleCard той же категории (иначе — свежие). SEO-перелинковка.
6. Footer + sticky CTA.
SEO: meta статей 1:1; Article JSON-LD — этап 4; заголовки/тексты не редактируются.

## /about
Хедер (H1 1:1) → цифры-факты (4, count-up) → фото-грид студии (studio-1/2 + 2–3 кадра из real works, у нас есть; при нехватке — 1–2 стоковых кадра оборудования, только Unsplash/Pexels/Pixabay с записью в content/photo-credits.md; изображения из поиска Google/Яндекс использовать запрещено) → блок «Как мы работаем со студией» (такси от 15к, фотоотчёты, гарантия — спокойным текстом) → квиз generic → footer. **Фото команды нет — секции команды не делаем.**

## /contacts
H1 1:1 → двухколонник: слева контакты крупно (телефон price-типографикой, WhatsApp/Telegram/Max кнопки, адрес пр-т Хусаина Ямашева 7к1, часы 10:00–20:00, «Оплатим такси…» строкой); **юрреквизиты пока не публикуем — блока нет** (решение владельца 01.09.2026); справа — Яндекс-карта (текущий embed, lazy, статичная картинка-плейсхолдер до клика). «Перезвоним за 28 сек» — удалено. Без формы: primary ведёт в WhatsApp.

DoD: оглавление и «читайте также» присутствуют на статьях, старый HTML статей не изменён (diff текста пуст), карта не грузится до взаимодействия, Lighthouse SEO 100 на всех четырёх.
