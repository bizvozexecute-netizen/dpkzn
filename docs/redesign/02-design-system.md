# 02 — Дизайн-система «Dark Studio» · dpkzn.ru

Пара к файлу `02-design-tokens.json`. Термины токенов: `bg` #0A0A0C, `surface` #141418, `line` rgba(255,255,255,.08), `ink` #F5F5F7, `ink-secondary` #8E8E93, `accent` = CSS-переменная (вариант выбирается в §2).

---

## 1. Принципы

1. **Машина — главный герой.** Самые светлые пиксели экрана — всегда фото/видео авто, не UI. Интерфейс тёмный и тихий, свет — на металле.
2. **Один акцент.** Акцентным цветом красятся только: главный CTA, активные состояния, подсветка «Анатомии». Никогда — заголовки, иконки «для красоты», фоны секций.
3. **Воздух вместо давления.** Секции 120–160px (desktop) / 64–96px (mobile). Один квиз на страницу, один sticky CTA. Никаких таймеров, слотов, процентов загрузки.
4. **Свет как в боксе.** Глубина строится не тенями, а светом: inset-блик по верхней кромке карточек (`shadow-card`), радиальные «прожекторы» над секциями (`studio-spot`), свечение акцента (`glow-accent`) только у ключевых интерактивов.
5. **Цены — моноширинные цифры.** `tabular-nums` во всех прайсах, ценах, счётчиках.

## 2. Акцент — 3 варианта на выбор

| | A. Янтарный `#F5A623` | B. Холодный синий `#4DA3FF` | C. Керамик-минт `#34D6B5` |
|---|---|---|---|
| Настроение | Тёплый свет малярной лампы на глянце; «ателье, ручная работа» | LED-свет детейлинг-бокса; «технологии, точность» | Цвет керамических составов; свежо, никто в нише не использует |
| Примеры применения | CTA «Расчёт по фото» янтарный на чёрном; подсветка зоны капота в «Анатомии» тёплым контуром; звёзды рейтинга и акцент сливаются в одну гамму (тепло) | CTA синий; «Анатомия» выглядит как HUD/рентген; хорошо дружит с фото ночного города и синих LED в боксе | CTA минт; линия глянца в before/after; перекликается с бутылками керамики на фото процессов |
| Риски | Похоже на такси/жёлтые маркетплейсы при передозировке — лечится дозировкой (см. принцип 2) | Самый «ожидаемый» цвет автосервисов, меньше отстройки | Требует дисциплины в фото (тёплые фото + холодный акцент могут спорить) |
| Контраст на #0A0A0C | 9.8:1 ✓ | 7.5:1 ✓ | 10.8:1 ✓ |
| Текст на акценте | #0A0A0C ✓ | #0A0A0C ✓ | #0A0A0C ✓ |

**Рекомендация: A (янтарный).** Тёплый акцент на холодном тёмном фоне — классика премиума (часы, авто-ателье), максимально отличает от синих сайтов автосервисов и точно попадает в метафору «машина под малярным светом». B — если хочется технологичности, C — если хочется уникальности гаммы. Смена варианта = 4 CSS-переменные, компоненты не трогаются.

## 3. Типографика

- **Display: Unbounded** (Google Fonts, кириллица; веса 500/600). Широкий, характерный — для H1/H2 и цифр-фактов. Только 2 веса, только заголовки.
- **Text: Inter** (Google Fonts, кириллица; 400/500/600). Всё остальное.
- Запасная пара, если Unbounded окажется слишком широким на живых макетах: **Oswald + Golos Text** (обе с кириллицей).
- Подключение — **self-host через `next/font`** (не CDN — надёжность в РФ + CLS = 0).
- Шкала: `display-1` 96 → `h1` 64 → `h2` 48 → `h3` 32 → `body` 17 (см. tokens, мобильные размеры через `clamp`). H1 на странице один, всегда `font-display`.
- Заголовки услуг пишем без Caps Lock — Unbounded сам по себе дисплейный, капс сделает его агрессивным.

## 4. Core-компоненты

### 4.1 Кнопка (Button)

Варианты: `primary` (акцент), `secondary` (обводка), `ghost` (текст), `messenger` (WhatsApp/Telegram/Max — иконка + текст, цвет бренда мессенджера только у иконки).

| Состояние | Primary | Secondary |
|---|---|---|
| Default | фон `accent`, текст `#0A0A0C`, radius `pill`, высота 56 (desktop) / 52 (mobile), padding-x 32, font 600 17px | фон прозрачный, border `line-strong`, текст `ink` |
| Hover | фон `accent-hover`, `glow-accent`, transition `base/out`; НЕ scale | border `accent` 40%, текст `ink` |
| Active/pressed | фон `accent-pressed`, glow выключается, translateY(1px) | фон `accent-subtle` |
| Focus-visible | outline 2px `accent` offset 2px | так же |
| Disabled | фон `surface2`, текст `ink-tertiary` | border `line`, текст `ink-tertiary` |
| Mobile | full-width внутри форм; в остальных местах по контенту | так же |

Правило: **primary — максимум один на вьюпорт** (не считая sticky CTA).

### 4.2 Карточка услуги (ServiceCard)

Для сетки услуг на главной и блока «Рекомендуемые услуги».

- Default: `surface`, border `line`, radius `lg`, padding 24; фото/иконка зоны авто сверху (соотношение 3:2, ч/б → цвет на hover), название `h4` display, цена «от N ₽» `caption` цветом `ink-secondary`, стрелка → в правом нижнем углу.
- Hover (desktop): scale 1.03 (`slow/out`), фото насыщается (grayscale 40% → 0), стрелка сдвигается на 4px вправо, border → `line-strong`, `shadow-card-hover`.
- Active: scale возвращается к 1.0 — «нажатие».
- Mobile: горизонтальный скролл-снап (карточка 280px) для длинных рядов ИЛИ сетка 2 колонки для главной; hover-эффектов нет, вся карточка — тап-зона ≥ 44px.
- Вся карточка — ссылка; заголовок не отдельный линк (один `<a>`).

### 4.3 Квиз-калькулятор (Quiz) — ЕДИНСТВЕННАЯ форма страницы

4 шага: класс авто (1–5 с примерами моделей, как в химчистке) → зона/объём работ (зависит от услуги) → срок («на этой неделе / в этом месяце / просто узнать цену») → контакт (телефон + выбор мессенджера WhatsApp/Telegram/Max/звонок).

- Контейнер: `elevated`, border `line`, radius `xl`, padding 40/24, заголовок `h3` + подпись «Расчёт по фото за 15 минут» `body-sm ink-secondary`.
- Прогресс: тонкая линия 2px сверху, заполнение `accent`, ширина = шаг/4; текст «Шаг 2 из 4» `caption`.
- Опции шага: радио-карточки (фон `surface`, border `line`, radius `md`, padding 16); hover — border `line-strong`; выбрано — border `accent`, фон `accent-subtle`, галочка `accent`. Переход шага: fade+slide 16px (`base/out`), высота контейнера анимируется.
- Шаг контакта: input телефона с маской +7, крупный (56px), primary-кнопка «Получить расчёт», под ней строка приватности `caption ink-tertiary`.
- Назад — ghost-стрелка слева от прогресса. Ошибки: border `error` + текст `caption error` под полем, shake 200ms.
- Mobile: шаги full-width, опции в столбец, кнопка full-width. Квиз НЕ модальный — это секция страницы.
- После отправки: состояние успеха внутри того же контейнера — галочка, «Заявка у мастера. Ответим в течение 15 минут в рабочее время», кнопки-ссылки на WhatsApp/Telegram.

### 4.4 Прайс-таблица (PriceTable)

Одна универсальная таблица под 3 модели прайса из инвентаризации (матрица классов / пакеты / одна цена). ОДИН экземпляр в DOM, адаптив через CSS.

- Desktop (матрица): первая колонка — пакет (название `body` 600 + состав `body-sm ink-secondary`), колонки классов 1–5 с примерами моделей в шапке (`caption`, две строки: «Класс 2» / «Camry, X3»); цены `price` tabular-nums. Пакет-хит: тег «Выбирают чаще» `caption` в `accent-subtle` (вместо «ХИТ» и скидок). Строка hover: фон `surface`. «Договорная» → «по осмотру».
- Пакеты без классов: карточки пакетов в ряд (3 шт), та же типографика, кнопка secondary «В расчёт» подставляет пакет в квиз (скролл к квизу).
- Поэлементный прайс: двухколоночный список «элемент — цена от», разделители `line`; > 8 позиций — сворачивание «Показать все элементы» (ghost).
- Mobile (матрица): селектор класса авто (сегмент-контрол pill, активный сегмент `accent-subtle` + border `accent`) → показываются цены выбранного класса как список пакетов. Это интерактив отображения, НЕ лид-форма.
- Под таблицей строка: «Точная цена — после осмотра или по фото» `body-sm ink-secondary`.

### 4.5 Before/After слайдер

- Контейнер radius `lg`, overflow hidden, соотношение 16:10; ручка — вертикальная линия 2px `ink` с круглой рукояткой 44px (иконка ⟷), тень `glow-accent` при захвате.
- Подписи «До»/«После» `overline` в углах на подложке `overlay` radius `sm`.
- Default: линия на 50%. Появление в вьюпорте: однократный автопроезд ручки 50→62→50% (`hero/in-out`) как подсказка интерактивности.
- Взаимодействие: drag + клик по любой точке; touch — drag; клавиатура — стрелки по 2%.
- Mobile: то же, соотношение 4:3.
- Без lazy-загрузки второй картинки в момент драга — обе загружены заранее (иначе дёргается).

### 4.6 Шапка + мегаменю (Header + MegaMenu)

- Высота 72 (desktop) / 60 (mobile). Фон: прозрачный поверх hero → `overlay` + blur(16px) + border-bottom `line` после скролла 40px (transition `base`).
- Состав: лого (моно-белый) · «Услуги» (мегаменю) · Портфолио · О студии · Блог · Контакты · справа телефон `body-sm` 600 + primary-кнопка «Расчёт» (компакт, высота 44).
- Мегаменю (hover с intent-задержкой 100ms / клик): полноширинная панель `elevated`, border-bottom `line`, 5 колонок по группам из инвентаризации (Защита / Оптика / Полировка и уход / Стайлинг и комфорт / Другое), **все 19 услуг** + строка цены «от N ₽» `caption ink-secondary` у каждой. Появление: fade + translateY(-8px) (`base/out`). Активная страница подсвечена `accent`.
- Mobile: бургер → полноэкранная панель `bg` со списком-аккордеоном групп, телефоны и мессенджеры внизу панели; body scroll lock.
- Скролл вниз >400px — шапка скрывается (translateY(-100%)), скролл вверх — возвращается (`base`). На странице с открытым мегаменю/панелью — не скрывается.

### 4.7 Футер (Footer)

- Фон `bg`, border-top `line`, секция `section-sm`.
- 4 колонки (desktop): лого + слоган + мессенджеры · Услуги (все 19, две подколонки `body-sm`) · Компания (Портфолио/О студии/Блог/Контакты) · Контакты (адрес пр-т Ямашева 7к1, часы 10:00–20:00, телефон крупно, «Оплатим такси до студии при заказе от 15 000 ₽» — спокойной строкой `body-sm ink-secondary`, без плашки).
- Нижняя строка: «Политика конфиденциальности» `caption ink-secondary`. Юрреквизиты не публикуем (решение владельца 01.09.2026) — места под них не резервируем.
- Mobile: аккордеоны для колонок услуг/компании, контакты развёрнуты.
- Никаких форм в футере.

### 4.8 Кейс-блок (CaseSpread)

Разворот кейса для портфолио и главной (4–6 машин, этап 4).

- Хедер кейса: фото на всю ширину (соотношение 21:9, hero-scrim), поверх — марка/модель `h2` display + теги услуг (pill, border `line-strong`) + факты строкой: срок / пакет / год `caption`.
- Тело: чередование «текст 4 колонки + фото 8 колонок» (сетка 12), блоки: Задача → Процесс (фото-ряд 2–3, scroll-reveal со stagger) → Результат (before/after слайдер или крупный глянец-кадр).
- Параллакс фото: фон-кадры двигаются на `parallax-max` 6% (`transform: translateY`, только desktop, только `IntersectionObserver` + rAF).
- Prev/next кейс: две карточки в конце (фото + марка), hover scale 1.03.
- Mobile: всё в одну колонку, параллакс выключен.
- Карточка кейса для сеток: фото 4:3, нижняя треть — scrim, марка `h4` display + услуги `caption ink-secondary`; hover: scale 1.03 + фото zoom 1.06 (`slow/out`).

### 4.9 «Анатомия детейлинга» (Anatomy) — ключевая фича

Интерактивная схема авто (вид 3/4, силуэт-иллюстрация в тонких линиях `line-strong` поверх тёмного фона, БЕЗ WebGL — инлайн SVG).

- Зоны: капот, бампер, фары, лобовое, крыша, двери/пороги, зеркала, диски/арки, салон, стёкла, хром-детали, днище. Каждая зона = `<path>` + точка-маркер (пульс 2s, `ink-tertiary`).
- Default: силуэт + маркеры; подпись «Наведите на зону» `caption ink-secondary` (на mobile — «Нажмите»).
- Hover/tap зоны: заливка зоны `accent-subtle`, контур `accent` (transition `fast`), рядом — карточка `elevated` (radius `md`, 280px): название зоны `h4`, услуги для зоны со строками «услуга — от N ₽» (ссылки), кнопка ghost «Подробнее →». Карточка появляется fade+slide 8px.
- Active (клик по услуге) — переход на страницу услуги.
- Mobile: схема сверху, карточка зоны — снизу закреплённой панелью (не поповер); зоны переключаются тапом.
- Клавиатура: зоны — фокусируемые элементы, Tab по порядку, Enter открывает карточку. `aria-expanded`, `role="button"`.
- Данные — JSON: `{zone, label, services: [{title, priceFrom, href}]}` — собирается из прайсов инвентаризации (этап 4).

### 4.10 Sticky CTA

- Desktop: закреплённая капсула справа внизу (offset 24): primary-кнопка «Расчёт по фото за 15 минут» + рядом две круглые иконки WhatsApp/Telegram (48px, `surface` + border `line`, иконка брендового цвета; Max — в раскрытии по клику на «+»). Появляется после скролла 1.5 вьюпорта, fade+slide 16px.
- Клик по primary: плавный скролл к квизу страницы (не модалка).
- Mobile: нижняя панель full-width (высота 64, `overlay` + blur, border-top `line`): primary «Расчёт по фото» (flex-1) + иконки WA/TG. Появляется после первого экрана, прячется при открытой клавиатуре и на шаге контакта квиза (чтобы не дублировать CTA).
- Никогда не перекрывает футер: за 100px до футера — position absolute.
- Один инстанс на страницу. Это ЕДИНСТВЕННЫЙ плавающий элемент сайта.

### 4.11 Карточка отзыва (ReviewCard)

- `surface`, border `line`, radius `lg`, padding 24: имя `body` 600 + звёзды (5 × 14px `rating-star`) + дата `caption ink-tertiary`, текст `body-sm` (кламп 5 строк, «Читать полностью» — раскрытие на месте), низ — бейдж «Яндекс.Карты» `caption` + марка авто, если есть.
- Лента: горизонтальный скролл-снап (карточка 360px) с кнопками ‹ › (desktop), свайп (mobile); НЕ автокарусель.
- Hover: border `line-strong`, без scale (текстовым блокам scale не даём).
- Рядом с заголовком секции: агрегат «5.0 · отзывы с Яндекс.Карт» + ссылка «Все отзывы» (org id 49387442667).

### 4.12 Карточка статьи (ArticleCard)

- Обложка 16:9 radius `lg` → категория `overline accent` → заголовок `h4` (кламп 2 строки) → дата + время чтения `caption ink-tertiary`.
- Hover: фото zoom 1.06 внутри контейнера (`slow/out`), заголовок → `accent` НЕТ — остаётся `ink` (акцент бережём), подчёркивание появляется.
- Featured-вариант (первая в списке блога): горизонтальная, фото 60%.
- Mobile: вертикальная, в один столбец; сетка блога desktop — 3 колонки.

## 5. Моушен: что анимируется, а что нет

**Анимируется (весь список — исчерпывающий):**

| Что | Как | Параметры |
|---|---|---|
| Hero | видео-луп 6–10с (muted, loop, playsinline, poster; ≤2.5MB, AV1/H265+H264 fallback) + заголовок fade-up | `hero/out`, задержка заголовка 200ms |
| Появление секций | scroll-reveal: opacity 0→1 + translateY 24px, один раз | `reveal/out`, threshold 0.2, stagger детей 80ms |
| Hover карточек с фото | scale 1.03 (карточка) / zoom 1.06 (фото внутри) | `slow/out` |
| Фото в кейсах | параллакс до 6% | rAF, только desktop |
| Before/after | drag + автоподсказка при появлении | `hero/in-out` |
| Анатомия | подсветка зон, пульс маркеров | `fast` |
| Квиз | переход шагов fade+slide 16px | `base/out` |
| Шапка / sticky CTA / мегаменю | появление/скрытие fade+slide | `base/out` |
| Цифры-факты (1200+ авто) | count-up при появлении, один раз | 1s, `out` |

**Не анимируется никогда:** текстовые абзацы после первого появления, прайс-таблицы (кроме hover строк), футер, breadcrumbs, звёзды рейтинга, фоновые частицы/шейдеры (их нет), автокарусели (их нет). Ничего не крутится и не двигается само, кроме видео-лупов и однократных reveal.

**Бюджет производительности:** анимируются только `transform` и `opacity` (никогда height/top/box-shadow в кадре; glow — через псевдоэлемент с opacity). Все reveal — `IntersectionObserver`, без scroll-листенеров. Библиотека — CSS + IO, без GSAP/Framer на страницах услуг (допустим Framer Motion точечно на главной, если Code решит). `prefers-reduced-motion` — см. tokens. LCP-элемент (hero-фото/постер) не анимируется до загрузки.

## 6. Доступность и инварианты

- Контрасты на `bg` (посчитаны): `ink` 18.2:1 ✓, `ink-secondary` 6.1:1 ✓ (AA для любого текста), `ink-tertiary` 3.9:1 — ТОЛЬКО для нетекстовых/декоративных элементов (разделители, плейсхолдеры графики) и текста ≥ 24px. Везде, где в §4 у caption/overline/дат указан `ink-tertiary` при 12–13px — читать как `ink-secondary` (исправление по итогам a11y-аудита фазы 0; код прав, а не ранняя редакция этого документа).
- Фокус видим на всех интерактивах (outline `accent`).
- Тап-зоны ≥ 44px. Слайдеры и анатомия управляются с клавиатуры.
- Один H1 на страницу; заголовки секций — H2 (SEO-структура из инвентаризации не ломается).
- Изображения: WebP/AVIF, `next/image`, размеры заданы (CLS 0); hero — `priority`.
