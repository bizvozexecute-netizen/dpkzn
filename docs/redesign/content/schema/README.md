# JSON-LD заготовки · dpkzn.ru

- localbusiness.json — вставляется в layout (одна на сайт, на всех страницах через @id-ссылку). Заполнить [LAT]/[LON] координатами студии (взять из Яндекс.Карт org/49387442667). aggregateRating НЕ добавляем, пока на странице нет собственного видимого блока отзывов с рейтингом (требование Google к самообслуживаемым рейтингам).
- service-template.json — шаблон для 19 страниц услуг; заполняется из данных страницы (см. 03-template-service.md §0). Пример заполнения — service-example-ppf.json.
- faqpage-template.json — генерируется из faq[] страницы, тексты 1:1 с видимым аккордеоном.
- Схема внедрения: <script type="application/ld+json"> в head соответствующей страницы; существующую разметку заменить этой (не дублировать типы).
- Для статей блога добавить Article (headline=H1, datePublished, image=обложка, author=Organization) — генерировать из данных статьи, отдельный файл не нужен.
